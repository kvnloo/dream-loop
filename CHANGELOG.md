# Changelog

## 2.0.0

### Changed

- Made dream-loop a project-agnostic visual iteration method for stills, Blender, Three.js, games and UI, rather than a default model/subscription-specific worker loop.
- Added scoped owner preferences, COPY/INTENT, exemplar/preflight gates, explicit current selection and per-batch owner checkpoints.
- Separated technical preservation, brief compliance and owner acceptance. Replaced score-only promotion with calibrated, fresh swapped A/B evidence and owner adjudication.
- Added final-density/max-zoom audits, style-layer contracts, component lanes, variant integration, domain packs and evaluation guidance.
- Added a stable defect ledger and guard against repeated failed focused attempts.
- Made structure-gate imports portable and included previously omitted right/bottom local windows.

### Added

- Portable semantic/grid tile splitter, verdict aggregation, native comparison sheets, A/B judge preparation/optional Hermes runner, integration adapter and schemas/templates.
- Offline test runner with receipts and failure propagation; skill frontmatter, Markdown link, JSON Schema and Python syntax lint.
- File-by-file reconciliation, standalone README with Hermes/Claude Code/Codex installation, contribution guidance and a prepared publication plan.

### Preserved from fork main

- Event-sourced Dream-RSI discovery ledger and legacy round API, byte-identical to PR #6's implementation/tests; v2 evidence remains in linked sidecars, with a single-writer requirement.
- Fal resumable submissions, uncertainty protection, bounded input validation, jailed paths, allowlisted downloads, GLB/PBR selection, terminal failure handling and serial concurrency setting.
- Local preview/capture server with atomic latest capture, compare page and dotfile denial; image-backend discovery (no generation or paid probes).
- Classic gated rubric/asset-first workflow, quota brakes, Pro/Plus recipes, asset/target/FPS/verdict schemas, onboarding and tiled mesh-map split/stitch helper.
- MIT notice, original project attribution, upstream illustration and both development histories via a merge commit.

### Retired as defaults (not deleted from history)

- Subscription/model-tier mandates, score thresholds as completion, default external-service consent, mandatory photorealism and blanket bans on approved Blender/procedural methods.
- Judge-history anchoring as promotion evidence, delayed owner checkpoints and unbounded small tweaks. Historical text is retained with explicit v2 overrides for reproducibility.

See [RECONCILE.md](RECONCILE.md) for exact file fates, tests and compatibility limits. Tests qualify machinery, not visual quality or owner acceptance. No release tag or GitHub release is created by this change.

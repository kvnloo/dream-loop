# Worker-plan completeness check

This checklist audits instructions, not actual execution. Each row needs a planned
step and later a receipt; a plan-only PASS never becomes artifact approval.

- [ ] Target/fixture/CURRENT identities, ART STYLE and COPY/INTENT; retain unknowns.
- [ ] Exact scoped owner preferences pasted into each brief/judge; lock only named
      attributes. Never invent target approval, source resolution or missing detail.
- [ ] Exemplar gate BEFORE production: native crop, structural reading, two causal
      form hypotheses under one objective, negative example, real coupon, owner.
- [ ] No-change baseline, calibrated hard gates; no hero-target comparison for
      untargeted alternate views; separate functional/phone/runtime checks.
- [ ] Actual receiver/material/computed-style/light/display preflight before renders.
- [ ] One attributable hypothesis with source-backed research and a control.
- [ ] **Before relying on judges**, owner-labelled anchors + known failures, held-out
      families, swap consistency, ties/abstention and explicit calibration limits.
      If labels are unavailable, mark judging uncalibrated and require owner decisions.
- [ ] Fresh swapped A/B; scope and deviations pasted; inspect actual native evidence
      paths/dimensions. Image budget is brief-specific, not a three-image platform cap.
- [ ] Max-zoom contract where relevant: >=1 effective source texel/final pixel BOTH
      directions; source/camera-projection audit, target pyramid, fixed full-density
      crops, sharpness/aliasing + texel metrics + native judge. Missing data is unknown.
- [ ] Style layers separated from materials; AI images may become authorized real
      baked mesh textures, never a 2D final-render paint-over under this method.
- [ ] Every-batch verified owner viewer checkpoint, including HOLD; stable defect
      ledger blocks a third failure trial pending owner strategy review.
- [ ] Frozen fixture, idempotent fixed-order integration, one postprocess owner,
      save/reopen guards; shared/per-variant config, history, immutable receipts.
- [ ] Technical, brief and owner gates distinct; selection/READY is not acceptance.

A permission question is not permission. A photograph *may* lack deepest-zoom detail:
audit before asserting it does. Do not infer scene-wide geometry locks from one
silhouette preference. Do not silently waive a stated deliverable for convenience;
show scope conflicts to the owner.

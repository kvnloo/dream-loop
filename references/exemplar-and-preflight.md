# Exemplar gate and receiver preflight

Approve the appearance family before optimizing it. A correct coat/glass/scatter
mechanism can still express the wrong form. Use [exemplar gate](../templates/exemplar-gate.md):
native target crop → structural reading → two genuinely distinct form hypotheses →
one negative example → small real coupon → owner approves the language. Hold the approved objective fixed: hypotheses must differ in causal construction, not invent a new objective such as “idealized instead of literal.” Resolve that intent question first. A whole
asset, large population or high samples comes later. Reuse approved exemplars for
small direct edits; do not force a costly tournament where intent is already exact.

Preflight actual receivers before rendering candidates. Use
[receiver receipt](../templates/receiver-preflight.md). In 3D inspect camera ray
hits, evaluated faces/normals, effective OBJECT/DATA material slots, reachable
shader links, UV/tangent domain, visibility, inherited contributors and light-link
receiver membership. Freeze exposure/view/look/glare with the fixture. In Three.js
include mesh.material assignments, tone mapping and draw state. In UI inspect
hit-tested elements, CSS cascade, fonts, stacking/clip state, theme tokens and DPR.
These are domain equivalents, not a requirement to ray-cast a static HTML page.

Observe intermediate masks, depth/normal/specular/emission passes or computed
layout when they answer a named uncertainty. “Looks absent” is a symptom; prove
whether the effect is absent, assigned elsewhere, hidden, mis-scaled or poorly lit.
A reference photograph does not contain queryable target topology.

Separate representation search from parameter fitting. Give alternatives different
causal constructions; keep the incumbent. After family approval, expose typed,
bounded, unit-aware controls and fit with deterministic sweeps/cheap checks where
useful. Search cannot reach a shape outside its generator's family. For an explicitly
coupled hypothesis (form + reflection source, layout + type measure), declare the
bundle and controls; the one-change-class rule must not forbid necessary physics.

Store the winner as a [visual skill packet](../templates/visual-skill-packet.md),
including failure examples, conditions and a held-out application. Documentation
reuse and plan compliance are not measured artistic transfer.

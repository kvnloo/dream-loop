# Target, style and acceptance contract

1. Discover originals, import manifests, past approved variants and reference crops before generating substitutes. Verify delivered hashes and permissions; a note saying “pending upload” is not proof the image is absent.
2. Name the deliverable: fixed still, movable 3D scene, interactive game, responsive page or deep-zoom master. Define camera/viewport/DPR, pose, animation time/seed, state and color pipeline. One locked frame may contain a whole environment, not necessarily one object. For responsive/motion products define a finite capture suite, with separate locked targets per state.
3. Name the ART STYLE from structure, not only nouns: angular facets with flat local tones, painterly marks, photoreal microstructure, graphic silhouette, etc. Ask how the owner reads it when ambiguous; “wet stone” can mean smooth cobbles to the agent and low-poly slate to the owner. Describe unit shape, scale distribution, coverage, edges, shading and negative space using native crops.
4. Write COPY/INTENT per element. COPY preserves the specified placement/identity literally within stated tolerances. INTENT adapts a look to actual geometry/layout. Record owner wording, protected graphics, allowed deviations, prohibited techniques and who may approve a revision. A generated reference can contain inconsistent perspective; do not deform protected geometry to reproduce it.
5. Preserve the original target bytes. A cleaned target is a separate candidate: remove blur/compression only, retain composition/objects/text/colors; compare subject, text and prop native crops before the owner locks it. Record generation route, prompt/revised prompt, dimensions and hashes. Restoration adds inferred detail, not recovered observations. Never silently sharpen a soft reference into a new truth.
6. Match evidence resolution honestly. Compare layout/light/color at matched viewing resolution; use sharper legitimate assets to author fine detail the target lacks. If native capture is absent, report the blocker or a mixed-resolution diagnostic; never relabel an upscale as native. Detail beyond source resolution is authored, scanned or synthesized and must downsample to the approved low-frequency image.
7. Re-dream only at an explicit checkpoint. Supply the current artifact as conditioning, state protected elements and desired new direction, preserve the old target and ledger, show alternatives, obtain a target revision decision, then restart baseline calibration. Re-dreaming is not a way to make a failing candidate win against a moving target.
8. Distinguish representation permissions: reference analysis/conditioning; approved projected artwork; relightable material; final compositing. No one permission implies the others. Keep private stills local unless external upload is explicitly authorized. “No downloaded assets” is not automatic permission for paid image-to-3D or public uploads.

Use [BRIEF](../templates/BRIEF.md) and canonical [OWNER-PREFERENCES](../templates/OWNER-PREFERENCES.md). Resolve scope and paste current applicable entries verbatim into every brief/judge packet, retaining hash/revision. Complete the [exemplar/style gate](exemplar-and-preflight.md) before full asset work.

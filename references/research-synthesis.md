# Research integration and evidence limits

The 2026-10 research lanes supplied source-backed strategies, not a universal AAA
benchmark. Keep paper/author results separate from local execution and owner approval.
The reusable rules below are integrated into the linked topic references.

| Input | Transferred method | Qualification / boundary |
|---|---|---|
| SOTA survey: BlenderAlchemy, ShaderAgent, VLMaterial, ProcFunc, SceneCraft, Voyager | Separate representation search and bounded numeric fitting; expressive typed components; intermediate previews; executable response-atlas library | Architecture lessons, not copied restricted code or reproduced published gains |
| Self-improvement audit | Exemplar gate, scoped preferences, actual receiver preflight, native owner-calibrated rankers, stable defect stop | Owner-authorized process improvements; no claim these already improve art |
| Classes | Deliberate practice: prediction, small coupon, falsifying control, inspection, reopen, delayed unseen transfer | Reported three mechanism labs/seven renders; not module graduation or production approval |
| Tools qualification | Audit versions/rights/security, probe real APIs, execute/reopen a bounded coupon, inspect actual appearance | A SAFE scan/install or valid constructor is not a finished graph or good art; qualify each path |
| Dream-RSI v2 | Discovery archive, fixed evaluator cohorts, prefix-only policy replay, incumbent/simple baselines, failure-aware portfolio | Replay cannot invent unseen interventions; offline selection earns only a live trial |
| Ecosystem review | Dependency closure, exact-vs-estimated replay, all-in costs, abstention, paired holdouts, delivered-vs-best | Official release exists; full trace corpus/harness experiment not established by that release |

## Operational synthesis

- Keep one art director/integrator; use bounded specialists for distinct uncertainties.
  Research/CPU preparation can overlap, not uncoordinated GPU renders. More agents
  or a new transport is not more artistic knowledge.
- Begin with existing assets and version-matched APIs. Do not delete the intended
  effect merely to silence an exception. Confirm the actual intervention executed.
- Reserve compute for useful information: graybox → integrated coupon → native
  ROI → full native → final-density check. Border glow/denoise needs context; final
  optics come from full-frame evidence. A budget is a ceiling with packaging reserve.
- Before a paid judge, log [self-review](../templates/self-review.md) and directive
  state. Diagnostic continuity can use history; blind promotion cannot.
- Retain successful anchors after failed children. Distinguish a located implementation
  bug from a failed mechanism. A portfolio may contain refinement, a distinct family,
  and at most one justified repair, only within the explicit defect stop/owner budget.
- Qualify tools by incremental capability and a bounded real test. Separate code,
  weights, data, fixtures and output licenses. Check telemetry/network/lifecycle and
  isolate untrusted add-ons. No cloud upload or paid call is authorized by a paper.
- Improve observation before replacing the model stack. Benchmark any builder,
  critic, retrieval or scheduler change separately with matched inputs/budgets.
- Practice with controls and negative examples; revisit after a gap on a different
  scale/light/style. Keep STUDIED, TECHNICAL, MECHANISM, TRANSFER and OWNER states
  separate. Never report training attendance from a catalog or transcript duration.

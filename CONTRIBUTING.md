# Contributing

This fork ([kvnloo/dream-loop](https://github.com/kvnloo/dream-loop)) welcomes pull requests. Dream Loop is MIT-licensed work by [Anshu Chimala](https://x.com/anshuc); keep that attribution.

## Protocol

Contributions should follow the [Verified OSS Loop](https://github.com/kvnloo/verified-oss-loop) contribution contract, in short:

1. **Orient** — read the skill and the existing Plus/Pro/classic split; match the current tree, not a deleted monolithic `SKILL.md`.
2. **Evidence** — include tests or a run receipt (`node --test scripts/*.test.mjs` for script changes; example screenshots or a short note for workflow copy). Bind claims to this revision.
3. **PR** — open against this repo. Maintainers merge; workers and bots do not.

If you change the loop, say which mode (Plus, Pro, Classic) you exercised and what still failed.

Please still include example results when a change could regress visual quality, as the upstream README asks.
